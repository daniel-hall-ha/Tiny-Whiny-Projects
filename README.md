# HTML, CSS & JavaScript Projects

A collection of beginner-friendly web projects built with HTML, CSS, and JavaScript to practice front-end development and JavaScript fundamentals.

## Projects

* **Restaurant Menu** – A simple restaurant menu interface.
* **Simple Interest Calculator** – Calculate simple interest from user inputs.
* **Task Tracker** – Track and manage daily tasks.
* **To Do List** – Add, complete, and remove to-do items.

## Technologies Used

* HTML
* CSS
* JavaScript

## Getting Started

1. Clone this repository.
2. Open any project's `index.html` file in your web browser.

## Purpose

This repository contains small practice projects created to improve front-end development skills and JavaScript programming.
